# MS-BASIC like Interpreter

(c) 2025 by Michael Stal

The interpreter is implemented in Go. It may be (cross-)compiled to any OS Go supports. You'll also find a USER and REFERENCE manual here (USER_MANUAL_AND_REFERENCE.txt). The interpreter consists of a single code file (src/msbasic.go).

<img width="1024" height="1536" alt="image" src="https://github.com/user-attachments/assets/ab5c6705-bf3e-4bcd-85ab-f07b348b2b3d" />


## Compile it

go build -o <your_executable_name> msbasic.go

First download the Go compiler for your OS, if you haven't done so yet.
