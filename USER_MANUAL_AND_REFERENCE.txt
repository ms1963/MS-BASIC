                          CHAPTER 1: GETTING STARTED

1.1 INSTALLATION
----------------

Prerequisites:
- Go programming language (version 1.16 or higher)
- Terminal or command prompt access
- Text editor (optional, for editing .BAS files)

Installation Steps:

1. Save the interpreter source code as 'msbasic.go'

2. Compile the interpreter:
   $ go build -o msbasic msbasic.go

3. Run the interpreter:
   $ ./msbasic

   On Windows:
   > msbasic.exe

4. You should see the welcome screen:

   ╔════════════════════════════════════════════════════════════╗
   ║   MS-BASIC Interpreter v4.0 FINAL (Complete & Debugged)   ║
   ║   All features implemented: LOAD, SAVE, FILES, KILL, NAME ║
   ║   Press Ctrl+C to stop running programs                   ║
   ╚════════════════════════════════════════════════════════════╝

   Commands: LOAD, SAVE, FILES, KILL, NAME, RUN, LIST, NEW, EXIT

   >


1.2 FIRST STEPS
---------------

The > prompt indicates the interpreter is ready for input.

Try these commands:

1. Print a message:
   > PRINT "Hello, World!"
   Hello, World!

2. Do some math:
   > PRINT 2 + 2
    4

3. Use variables:
   > X = 10
   > PRINT X * 5
    50

4. Exit the interpreter:
   > EXIT


1.3 STOPPING PROGRAMS
---------------------

**IMPORTANT: Ctrl+C Support**

You can stop a running program at any time by pressing Ctrl+C (Control+C).
This will interrupt the program and return you to the command prompt WITHOUT
exiting the interpreter.

Example:
   > 10 FOR I = 1 TO 1000000
   > 20 PRINT I
   > 30 NEXT I
   > RUN
    1
    2
    3
   (Press Ctrl+C)
   *** BREAK ***
   >

The program stops immediately and you can continue using the interpreter.

Other ways to stop programs:
- STOP statement in your code
- END statement in your code
- Natural program completion


1.4 INTERACTIVE MODE vs PROGRAM MODE
-------------------------------------

INTERACTIVE MODE:
Commands are executed immediately when you press Enter.

Example:
   > PRINT "Immediate"
   Immediate

PROGRAM MODE:
Lines starting with numbers are stored in memory for later execution.

Example:
   > 10 PRINT "Stored"
   > 20 PRINT "For later"
   > RUN
   Stored
   For later

                          CHAPTER 2: BASIC CONCEPTS
================================================================================

2.1 LINE NUMBERS
----------------

Programs are organized using line numbers (1-65535).

Rules:
- Line numbers must be positive integers
- They don't need to be consecutive
- Common practice: number by 10s (10, 20, 30...) to allow insertions

Example:
   10 PRINT "First"
   20 PRINT "Second"
   30 PRINT "Third"

To insert a line between 10 and 20:
   15 PRINT "Between first and second"

To delete a line:
   15

To replace a line:
   20 PRINT "New second line"


2.2 COMMENTS
------------

Two ways to add comments:

1. REM statement:
   10 REM This is a comment
   20 PRINT "Hello"

2. Apostrophe ('):
   10 ' This is also a comment
   20 PRINT "Hello"

Comments are ignored during execution.


2.3 CASE SENSITIVITY
--------------------

MS-BASIC is NOT case sensitive for keywords and variable names.

These are equivalent:
   PRINT "Hello"
   print "Hello"
   PrInT "Hello"

Variable names:
   X = 10
   x = 20    ' Same variable, now equals 20


2.4 STATEMENT SEPARATORS
-------------------------

Multiple statements can be on one line using colons (:)

Example:
   10 X = 5 : Y = 10 : PRINT X + Y

================================================================================
                    CHAPTER 5: VARIABLES AND DATA TYPES
================================================================================

5.1 VARIABLE TYPES
------------------

MS-BASIC supports five data types:

1. SINGLE-PRECISION (!) - Default floating point
   Range: ±1.5E-45 to ±3.4E38
   Example: X = 3.14159
            Y! = 2.5

2. DOUBLE-PRECISION (#) - High-precision floating point
   Range: ±5.0E-324 to ±1.7E308
   Example: PI# = 3.14159265358979

3. INTEGER (%) - Whole numbers
   Range: -32,768 to 32,767
   Example: COUNT% = 100

4. LONG INTEGER (&) - Large whole numbers
   Range: -2,147,483,648 to 2,147,483,647
   Example: BIGNUM& = 1000000

5. STRING ($) - Text
   Length: Up to available memory
   Example: NAME$ = "John Smith"


5.2 VARIABLE NAMING RULES
--------------------------

Rules:
- Must start with a letter (A-Z)
- Can contain letters, numbers, and periods
- Maximum 40 characters
- Type suffix (%, &, #, $, !) is part of the name
- Not case sensitive

Valid names:
   X
   TOTAL
   FIRST.NAME$
   COUNT%
   AMOUNT#

Invalid names:
   9X          (starts with number)
   MY-VAR      (contains hyphen)
   FIRST NAME  (contains space)


5.3 DEFAULT TYPES WITH DEFTYPE
-------------------------------

Set default type for variables starting with specific letters:

   DEFINT A-Z      ' All variables are integers by default
   DEFSTR S        ' Variables starting with S are strings
   DEFSNG F-H      ' F, G, H variables are single-precision
   DEFDBL D        ' D variables are double-precision
   DEFLNG L        ' L variables are long integers

Example:
   10 DEFINT I-N
   20 DEFSTR S
   30 I = 10        ' Integer (because of DEFINT)
   40 X = 3.14      ' Single-precision (default)
   50 S = "Hello"   ' String (because of DEFSTR)


5.4 NUMERIC CONSTANTS
---------------------

Decimal:
   10
   3.14159
   -25.5

Hexadecimal (base 16):
   &HFF        ' 255 in decimal
   &H10        ' 16 in decimal

Octal (base 8):
   &O77        ' 63 in decimal
   &17         ' 15 in decimal (& prefix)

Scientific notation:
   1.5E10      ' 15,000,000,000
   2.5E-3      ' 0.0025


5.5 STRING CONSTANTS
--------------------

Enclosed in double quotes:
   "Hello, World!"
   "123 Main Street"
   ""              ' Empty string

Strings can contain any printable character.


================================================================================
                      CHAPTER 6: CONTROL STRUCTURES
================================================================================

6.1 IF-THEN-ELSE
----------------

Simple IF:
   10 IF X > 10 THEN PRINT "X is large"

IF-THEN-ELSE:
   10 IF X > 10 THEN PRINT "Large" ELSE PRINT "Small"

Multi-line IF:
   10 IF X > 10 THEN
   20     PRINT "X is large"
   30     PRINT "Very large indeed"
   40 ELSE
   50     PRINT "X is small"
   60 END IF

IF with GOTO:
   10 IF X > 10 THEN GOTO 100
   20 PRINT "X is small"
   30 END
   100 PRINT "X is large"

Nested IF:
   10 IF X > 0 THEN
   20     IF X < 10 THEN
   30         PRINT "X is between 0 and 10"
   40     END IF
   50 END IF


6.2 FOR-NEXT LOOPS
------------------

Basic FOR loop:
   10 FOR I = 1 TO 10
   20     PRINT I
   30 NEXT I

With STEP:
   10 FOR I = 0 TO 100 STEP 10
   20     PRINT I
   30 NEXT I

Counting backwards:
   10 FOR I = 10 TO 1 STEP -1
   20     PRINT I
   30 NEXT I

Nested loops:
   10 FOR I = 1 TO 5
   20     FOR J = 1 TO 5
   30         PRINT I * J;
   40     NEXT J
   50     PRINT
   60 NEXT I


6.3 WHILE-WEND LOOPS
--------------------

Basic WHILE:
   10 X = 1
   20 WHILE X <= 10
   30     PRINT X
   40     X = X + 1
   50 WEND

With condition:
   10 INPUT "Enter password: ", PASS$
   20 WHILE PASS$ <> "SECRET"
   30     PRINT "Wrong password!"
   40     INPUT "Try again: ", PASS$
   50 WEND
   60 PRINT "Access granted"


6.4 GOTO AND GOSUB
------------------

GOTO - Jump to a line number:
   10 PRINT "Start"
   20 GOTO 40
   30 PRINT "Skipped"
   40 PRINT "End"

GOSUB - Call a subroutine:
   10 GOSUB 100
   20 PRINT "Back from subroutine"
   30 END
   100 REM Subroutine
   110 PRINT "In subroutine"
   120 RETURN

Multiple subroutines:
   10 GOSUB 100
   20 GOSUB 200
   30 END
   100 PRINT "First subroutine"
   110 RETURN
   200 PRINT "Second subroutine"
   210 RETURN


6.5 ON-GOTO and ON-GOSUB
------------------------

ON-GOTO - Computed GOTO:
   10 INPUT "Choose 1, 2, or 3: ", N
   20 ON N GOTO 100, 200, 300
   30 END
   100 PRINT "You chose 1": END
   200 PRINT "You chose 2": END
   300 PRINT "You chose 3": END

ON-GOSUB - Computed GOSUB:
   10 INPUT "Menu choice: ", N
   20 ON N GOSUB 100, 200, 300
   30 END
   100 PRINT "Option 1": RETURN
   200 PRINT "Option 2": RETURN
   300 PRINT "Option 3": RETURN


6.6 COMPARISON OPERATORS
------------------------

=       Equal to
<>      Not equal to
<       Less than
>       Greater than
<=      Less than or equal to
>=      Greater than or equal to

Examples:
   IF X = 10 THEN PRINT "Equal"
   IF X <> 10 THEN PRINT "Not equal"
   IF X < 10 THEN PRINT "Less"
   IF X > 10 THEN PRINT "Greater"
   IF X <= 10 THEN PRINT "Less or equal"
   IF X >= 10 THEN PRINT "Greater or equal"


6.7 LOGICAL OPERATORS
---------------------

AND     Logical AND
OR      Logical OR
NOT     Logical NOT
XOR     Exclusive OR
EQV     Equivalence
IMP     Implication

Examples:
   10 IF X > 0 AND X < 10 THEN PRINT "In range"
   20 IF X < 0 OR X > 100 THEN PRINT "Out of range"
   30 IF NOT (X = 0) THEN PRINT "Not zero"

Truth tables:

AND:  -1 AND -1 = -1    (true AND true = true)
      -1 AND  0 =  0    (true AND false = false)
       0 AND -1 =  0    (false AND true = false)
       0 AND  0 =  0    (false AND false = false)

OR:   -1 OR -1 = -1     (true OR true = true)
      -1 OR  0 = -1     (true OR false = true)
       0 OR -1 = -1     (false OR true = true)
       0 OR  0 =  0     (false OR false = false)

NOT:  NOT -1 = 0        (NOT true = false)
      NOT  0 = -1       (NOT false = true)


================================================================================
                            CHAPTER 7: ARRAYS
================================================================================

7.1 DECLARING ARRAYS
--------------------

Use DIM to declare arrays:

   DIM A(10)           ' Single-precision array, 11 elements (0-10)
   DIM B%(100)         ' Integer array, 101 elements
   DIM NAMES$(50)      ' String array, 51 elements
   DIM VALUES#(25)     ' Double-precision array, 26 elements

By default, arrays start at index 0.


7.2 OPTION BASE
---------------

Change the starting index:

   OPTION BASE 1       ' Arrays start at 1
   DIM A(10)           ' Now has elements 1-10 (10 elements)

   OPTION BASE 0       ' Arrays start at 0 (default)
   DIM B(10)           ' Has elements 0-10 (11 elements)

OPTION BASE must be used before any DIM statements.


7.3 USING ARRAYS
----------------

Assign values:
   10 DIM SCORES(5)
   20 SCORES(0) = 85
   30 SCORES(1) = 92
   40 SCORES(2) = 78
   50 SCORES(3) = 95
   60 SCORES(4) = 88
   70 SCORES(5) = 91

Access values:
   80 PRINT SCORES(0)
   90 TOTAL = SCORES(0) + SCORES(1) + SCORES(2)

Loop through array:
   10 DIM A(10)
   20 FOR I = 0 TO 10
   30     A(I) = I * 2
   40 NEXT I
   50 FOR I = 0 TO 10
   60     PRINT A(I)
   70 NEXT I


7.4 STRING ARRAYS
-----------------

   10 DIM NAMES$(5)
   20 NAMES$(0) = "Alice"
   30 NAMES$(1) = "Bob"
   40 NAMES$(2) = "Charlie"
   50 FOR I = 0 TO 2
   60     PRINT NAMES$(I)
   70 NEXT I


7.5 ARRAY BOUNDS
----------------

LBOUND - Get lower bound:
   10 DIM A(10)
   20 PRINT LBOUND(A)      ' Prints 0 (or 1 with OPTION BASE 1)

UBOUND - Get upper bound:
   10 DIM A(10)
   20 PRINT UBOUND(A)      ' Prints 10


7.6 ERASING ARRAYS
------------------

Free memory used by arrays:

   10 DIM TEMP(1000)
   20 ' Use the array...
   30 ERASE TEMP           ' Free the memory

You can erase multiple arrays:
   ERASE A, B, C


================================================================================
                       CHAPTER 8: FILE OPERATIONS
================================================================================

8.1 OPENING FILES
-----------------

OPEN "filename" FOR mode AS #filenumber

Modes:
- INPUT   : Read from file
- OUTPUT  : Write to file (creates new or overwrites)
- APPEND  : Add to end of file

Examples:
   OPEN "DATA.TXT" FOR INPUT AS #1
   OPEN "OUTPUT.TXT" FOR OUTPUT AS #2
   OPEN "LOG.TXT" FOR APPEND AS #3


8.2 CLOSING FILES
-----------------

Close a specific file:
   CLOSE #1

Close multiple files:
   CLOSE #1, #2, #3

Close all files:
   CLOSE


8.3 WRITING TO FILES
--------------------

WRITE # - Write data to file:
   10 OPEN "DATA.TXT" FOR OUTPUT AS #1
   20 WRITE #1, "John", 25, 50000
   30 WRITE #1, "Jane", 30, 60000
   40 CLOSE #1

PRINT # - Print to file:
   10 OPEN "REPORT.TXT" FOR OUTPUT AS #1
   20 PRINT #1, "Sales Report"
   30 PRINT #1, "============"
   40 PRINT #1, "Total: $"; 1234.56
   50 CLOSE #1


8.4 READING FROM FILES
----------------------

INPUT # - Read data from file:
   10 OPEN "DATA.TXT" FOR INPUT AS #1
   20 INPUT #1, NAME$, AGE, SALARY
   30 PRINT NAME$; AGE; SALARY
   40 CLOSE #1

LINE INPUT # - Read entire line:
   10 OPEN "TEXT.TXT" FOR INPUT AS #1
   20 LINE INPUT #1, LINE$
   30 PRINT LINE$
   40 CLOSE #1


8.5 FILE FUNCTIONS
------------------

EOF(n) - Check if end of file:
   10 OPEN "DATA.TXT" FOR INPUT AS #1
   20 WHILE NOT EOF(1)
   30     LINE INPUT #1, LINE$
   40     PRINT LINE$
   50 WEND
   60 CLOSE #1

LOF(n) - Get file length:
   10 OPEN "DATA.TXT" FOR INPUT AS #1
   20 PRINT "File size:"; LOF(1); "bytes"
   30 CLOSE #1

LOC(n) - Get current position:
   10 OPEN "DATA.TXT" FOR INPUT AS #1
   20 PRINT "Current line:"; LOC(1)
   30 CLOSE #1


8.6 COMPLETE FILE EXAMPLE
--------------------------

Write to file:
   10 REM Write data to file
   20 OPEN "CONTACTS.TXT" FOR OUTPUT AS #1
   30 FOR I = 1 TO 3
   40     INPUT "Name: ", N$
   50     INPUT "Phone: ", P$
   60     WRITE #1, N$, P$
   70 NEXT I
   80 CLOSE #1
   90 PRINT "Data saved!"

Read from file:
   10 REM Read data from file
   20 OPEN "CONTACTS.TXT" FOR INPUT AS #1
   30 WHILE NOT EOF(1)
   40     INPUT #1, N$, P$
   50     PRINT N$; " - "; P$
   60 WEND
   70 CLOSE #1


================================================================================
                       CHAPTER 9: ERROR HANDLING
================================================================================

9.1 ON ERROR GOTO
-----------------

Enable error handling:
   10 ON ERROR GOTO 1000
   20 ' Your code here
   30 ' ...
   40 END
   1000 REM Error handler
   1010 PRINT "Error occurred!"
   1020 END

Disable error handling:
   ON ERROR GOTO 0


9.2 ERROR FUNCTIONS
-------------------

ERR - Get error number:
   1000 PRINT "Error number:"; ERR

ERL - Get line number where error occurred:
   1000 PRINT "Error at line:"; ERL

Common error codes:
   2   - Syntax error
   5   - Illegal function call
   6   - Overflow
   7   - Out of memory
   9   - Subscript out of range
   11  - Division by zero
   13  - Type mismatch
   53  - File not found


9.3 RESUME
----------

RESUME - Return to line that caused error:
   1000 PRINT "Error occurred"
   1010 RESUME

RESUME NEXT - Continue with next line:
   1000 PRINT "Error occurred, continuing..."
   1010 RESUME NEXT

RESUME line - Continue at specific line:
   1000 PRINT "Error occurred"
   1010 RESUME 100


9.4 ERROR HANDLING EXAMPLE
---------------------------

   10 ON ERROR GOTO 1000
   20 INPUT "Enter a number: ", N
   30 RESULT = 100 / N
   40 PRINT "Result:"; RESULT
   50 END
   1000 REM Error handler
   1010 IF ERR = 11 THEN
   1020     PRINT "Cannot divide by zero!"
   1030     RESUME 20
   1040 ELSE
   1050     PRINT "Error"; ERR; "at line"; ERL
   1060     END
   1070 END IF

10.1 DATA AND READ
------------------

Store data in program:

10.2 RANDOMIZE
--------------

Seed random number generator:
   RANDOMIZE        ' Use current time
   RANDOMIZE 12345  ' Use specific seed


10.3 SWAP
---------

Exchange values of two variables:
   10 A = 10
   20 B = 20
   30 SWAP A, B
   40 PRINT A; B    ' Prints 20 10


10.4 MEMORY OPERATIONS
----------------------

PEEK - Read memory location:
   VALUE = PEEK(1000)

POKE - Write to memory location:
   POKE 1000, 255

FRE - Get free memory:
   PRINT "Free memory:"; FRE(0)


10.5 CURSOR CONTROL
-------------------

CLS - Clear screen:
   CLS

LOCATE - Position cursor:
   LOCATE 10, 20    ' Row 10, Column 20

POS - Get cursor column:
   X = POS(0)


10.6 TIME AND DATE
------------------

TIMER - Seconds since midnight:
   START = TIMER

   ELAPSED = TIMER - START
   PRINT "Elapsed:"; ELAPSED; "seconds"

TIME$ - Current time:
   PRINT TIME$      ' Prints HH:MM:SS

DATE$ - Current date:
   PRINT DATE$      ' Prints MM-DD-YYYY

================================================================================
                        CHAPTER 11: SYSTEM COMMANDS
================================================================================

NEW
---
Syntax: NEW
Purpose: Clear program and variables from memory
Example:
   > NEW
   Ready

Notes:
- Closes all open files
- Clears all variables
- Erases program from memory
- Does not affect files on disk


LIST
----
Syntax: LIST [start[-end]]
Purpose: Display program lines
Examples:
   LIST              ' List entire program
   LIST 100          ' List line 100
   LIST 100-200      ' List lines 100 to 200

Notes:
- Lines are displayed in numerical order
- Shows line numbers and code


RUN
---
Syntax: RUN [line]
Purpose: Execute the program
Examples:
   RUN               ' Run from first line
   RUN 100           ' Run starting at line 100

Notes:
- Clears all variables before running
- Closes all open files
- Press Ctrl+C to stop execution


EXIT
----
Syntax: EXIT
Purpose: Quit the interpreter
Example:
   > EXIT
   Goodbye!

Notes:
- Closes all open files
- Does not save program automatically


LOAD
----
Syntax: LOAD "filename"
Purpose: Load program from disk
Examples:
   LOAD "MYPROG"
   LOAD "MYPROG.BAS"

Notes:
- Clears current program first
- .BAS extension added if not specified
- File must exist or error occurs


SAVE
----
Syntax: SAVE "filename"
Purpose: Save program to disk
Examples:
   SAVE "MYPROG"
   SAVE "MYPROG.BAS"

Notes:
- Overwrites existing file
- .BAS extension added if not specified
- Creates new file if doesn't exist


FILES
-----
Syntax: FILES
Purpose: List all .BAS files in current directory
Example:
   > FILES

   BASIC Program Files:
   --------------------
   GAME.BAS                1024 bytes
   TEST.BAS                 256 bytes

   2 file(s)


KILL
----
Syntax: KILL "filename"
Purpose: Delete a file
Example:
   KILL "OLDPROG.BAS"

Notes:
- File is permanently deleted
- No confirmation prompt
- Error if file doesn't exist


NAME
----
Syntax: NAME "oldname" AS "newname"
Purpose: Rename a file
Example:
   NAME "OLD.BAS" AS "NEW.BAS"

Notes:
- Overwrites newname if it exists
- Error if oldname doesn't exist


================================================================================
                   CHAPTER 12: PROGRAM CONTROL COMMANDS
================================================================================

GOTO
----
Syntax: GOTO line
Purpose: Jump to specified line
Example:
   10 PRINT "Start"
   20 GOTO 40
   30 PRINT "Skipped"
   40 PRINT "End"

Notes:
- Unconditional jump
- Line must exist


GOSUB
-----
Syntax: GOSUB line
Purpose: Call a subroutine
Example:
   10 GOSUB 100
   20 PRINT "Back"
   30 END
   100 PRINT "In subroutine"
   110 RETURN

Notes:
- Must have matching RETURN
- Can nest subroutines


RETURN
------
Syntax: RETURN
Purpose: Return from subroutine
Example:
   100 PRINT "Subroutine"
   110 RETURN

Notes:
- Returns to line after GOSUB
- Error if no matching GOSUB


ON GOTO
-------
Syntax: ON expression GOTO line1, line2, ...
Purpose: Computed GOTO
Example:
   10 INPUT "Choice (1-3): ", N
   20 ON N GOTO 100, 200, 300

Notes:
- Expression must be 1, 2, 3, etc.
- If out of range, continues to next line


ON GOSUB
--------
Syntax: ON expression GOSUB line1, line2, ...
Purpose: Computed GOSUB
Example:
   10 INPUT "Menu: ", N
   20 ON N GOSUB 100, 200, 300

Notes:
- Similar to ON GOTO but calls subroutines
- Each subroutine must RETURN


IF-THEN-ELSE
------------
Syntax: IF condition THEN statement [ELSE statement]
Purpose: Conditional execution
Examples:
   IF X > 10 THEN PRINT "Large"
   IF X > 10 THEN PRINT "Large" ELSE PRINT "Small"
   IF X > 10 THEN GOTO 100
   IF X > 10 THEN GOSUB 100 ELSE GOSUB 200

Notes:
- Condition: -1 = true, 0 = false
- Can use any comparison or logical operator


FOR-NEXT
--------
Syntax: FOR variable = start TO end [STEP increment]
        NEXT [variable]
Purpose: Loop with counter
Examples:
   FOR I = 1 TO 10
       PRINT I
   NEXT I

   FOR I = 10 TO 1 STEP -1
       PRINT I
   NEXT I

Notes:
- Default STEP is 1
- STEP can be negative
- Loop executes at least once if start <= end


WHILE-WEND
----------
Syntax: WHILE condition
        WEND
Purpose: Loop while condition is true
Example:
   10 X = 1
   20 WHILE X <= 10
   30     PRINT X
   40     X = X + 1
   50 WEND

Notes:
- Condition checked before each iteration
- May not execute at all if initially false


END
---
Syntax: END
Purpose: Terminate program
Example:
   10 PRINT "Done"
   20 END

Notes:
- Closes all files
- Stops execution
- Optional at end of program


STOP
----
Syntax: STOP
Purpose: Halt program with message
Example:
   10 PRINT "Stopping"
   20 STOP

Output:
   Stopping
   BREAK

Notes:
- Similar to END but displays "BREAK"
- Used for debugging

Linear Search:

   20 DIM A(100)
   30 N = 20

   50     A(I) = I * 5
   60 NEXT I
   70 INPUT "Search for: ", TARGET
   80 FOUND = 0
   90 FOR I = 1 TO N
   100     IF A(I) = TARGET THEN
   110         PRINT "Found at index"; I
   120         FOUND = -1
   130         GOTO 160
   140     END IF
   150 NEXT I
   160 IF NOT FOUND THEN PRINT "Not found"

Binary Search (array must be sorted):
   10 REM Binary Search
   20 DIM A(100)
   30 N = 20
   40 FOR I = 1 TO N
   50     A(I) = I * 5
   60 NEXT I
   70 INPUT "Search for: ", TARGET
   80 LEFT = 1
   90 RIGHT = N
   100 FOUND = 0
   110 WHILE LEFT <= RIGHT AND NOT FOUND
   120     MID = INT((LEFT + RIGHT) / 2)
   130     IF A(MID) = TARGET THEN
   140         PRINT "Found at index"; MID
   150         FOUND = -1
   160     ELSE IF A(MID) < TARGET THEN
   170         LEFT = MID + 1
   180     ELSE
   190         RIGHT = MID - 1
   200     END IF
   210 WEND
   220 IF NOT FOUND THEN PRINT "Not found"

A.6 STATISTICAL CALCULATIONS
-----------------------------

Mean and Standard Deviation:
   10 REM Calculate statistics
   20 DIM DATA(100)
   30 N = 20
   40 REM Fill with data
   50 FOR I = 1 TO N
   60     DATA(I) = INT(RND * 100)
   70 NEXT I
   80 REM Calculate mean
   90 SUM = 0
   100 FOR I = 1 TO N
   110     SUM = SUM + DATA(I)
   120 NEXT I
   130 MEAN = SUM / N
   140 REM Calculate standard deviation
   150 SUMDEV = 0
   160 FOR I = 1 TO N
   170     DEV = DATA(I) - MEAN
   180     SUMDEV = SUMDEV + DEV * DEV
   190 NEXT I
   200 STDDEV = SQR(SUMDEV / N)
   210 PRINT "Mean:"; MEAN
   220 PRINT "Std Dev:"; STDDEV

   80 PRINT "DATABASE MENU"
   90 PRINT "1. Add Record"
   100 PRINT "2. Display All"
   110 PRINT "3. Search"
   120 PRINT "4. Exit"
   130 INPUT "Choice: ", C
   140 ON C GOSUB 1000, 2000, 3000
   150 IF C <> 4 THEN GOTO 70
   160 END
   1000 REM Add record
   1010 IF NUMRECS >= 100 THEN
   1020     PRINT "Database full!"
   1030     RETURN
   1040 END IF
   1050 NUMRECS = NUMRECS + 1
   1060 INPUT "Name: ", RECORDS$(NUMRECS, 1)
   1070 INPUT "Age: ", RECORDS$(NUMRECS, 2)
   1080 INPUT "City: ", RECORDS$(NUMRECS, 3)
   1090 RETURN
   2000 REM Display all
   2010 FOR I = 1 TO NUMRECS
   2020     PRINT I; ". ";
   2030     FOR J = 1 TO COLS
   2040         PRINT RECORDS$(I, J); " ";
   2050     NEXT J
   2060     PRINT
   2070 NEXT I
   2080 INPUT "Press Enter", D$
   2090 RETURN
   3000 REM Search

   3020 FOR I = 1 TO NUMRECS
   3030     IF INSTR(UCASE$(RECORDS$(I, 1)), UCASE$(S$)) > 0 THEN
   3040         PRINT RECORDS$(I, 1); " - ";
   3050         PRINT RECORDS$(I, 2); " - ";
   3060         PRINT RECORDS$(I, 3)
   3070     END IF
   3080 NEXT I
   3090 INPUT "Press Enter", D$
   3100 RETURN


B.3 TEXT ADVENTURE GAME
-----------------------

   10 REM *** TEXT ADVENTURE ***
   20 OPTION BASE 1
   30 DIM ROOM$(5), ITEM$(5)
   40 REM Initialize
   50 ROOM$(1) = "You are in a dark cave."
   60 ROOM$(2) = "You are in a forest."
   70 ROOM$(3) = "You are at a river."
   80 ROOM$(4) = "You are on a mountain."
   90 ROOM$(5) = "You are in a castle."
   100 ITEM$(1) = "torch"
   110 ITEM$(2) = "sword"
   120 ITEM$(3) = "boat"
   130 ITEM$(4) = "rope"
   140 ITEM$(5) = "key"
   150 LOCATION = 1
   160 INVENTORY$ = ""
   170 REM Game loop
   180 CLS
   190 PRINT ROOM$(LOCATION)
   200 IF ITEM$(LOCATION) <> "" THEN
   210     PRINT "You see a "; ITEM$(LOCATION); "."
   220 END IF
   230 PRINT
   240 INPUT "What do you do? ", CMD$
   250 CMD$ = UCASE$(CMD$)
   260 IF LEFT$(CMD$, 2) = "GO" THEN GOSUB 1000
   270 IF LEFT$(CMD$, 4) = "TAKE" THEN GOSUB 2000
   280 IF LEFT$(CMD$, 4) = "LOOK" THEN GOTO 180
   290 IF LEFT$(CMD$, 4) = "QUIT" THEN END
   300 GOTO 180
   1000 REM Movement
   1010 IF INSTR(CMD$, "NORTH") THEN
   1020     LOCATION = LOCATION - 1
   1030 ELSE IF INSTR(CMD$, "SOUTH") THEN
   1040     LOCATION = LOCATION + 1
   1050 END IF
   1060 IF LOCATION < 1 THEN LOCATION = 1
   1070 IF LOCATION > 5 THEN LOCATION = 5
   1080 RETURN
   2000 REM Take item
   2010 IF ITEM$(LOCATION) = "" THEN
   2020     PRINT "Nothing to take!"
   2030     INPUT "Press Enter", D$
   2040     RETURN
   2050 END IF
   2060 INVENTORY$ = INVENTORY$ + ITEM$(LOCATION) + " "
   2070 PRINT "Taken: "; ITEM$(LOCATION)
   2080 ITEM$(LOCATION) = ""
   2090 INPUT "Press Enter", D$
   2100 RETURN

C.1 COMMON ERRORS
-----------------

"Syntax error"
- Check for missing keywords
- Verify proper statement structure
- Check for unmatched quotes
- Ensure proper use of operators

"Type mismatch"
- Verify variable types match usage
- Check string vs numeric operations
- Ensure array types are consistent

"Subscript out of range"
- Check array bounds
- Verify OPTION BASE setting
- Ensure index is within DIM size

"Division by zero"
- Check divisor before dividing
- Add error handling
- Validate input data

"Out of memory"
- Reduce array sizes
- ERASE unused arrays
- Close unused files
- Clear unused variables

"File not found"
- Check filename spelling
- Verify file exists
- Check file path
- Ensure .BAS extension if needed

"RETURN without GOSUB"
- Verify GOSUB/RETURN pairs
- Check program flow
- Ensure RETURN is in subroutine

"NEXT without FOR"
- Check FOR/NEXT pairs
- Verify loop variable names match
- Ensure proper nesting

"WEND without WHILE"
- Check WHILE/WEND pairs
- Verify proper nesting


C.2 DEBUGGING TECHNIQUES
------------------------

Add PRINT statements:
   10 X = 10
   15 PRINT "DEBUG: X ="; X
   20 Y = X * 2
   25 PRINT "DEBUG: Y ="; Y

Use STOP to pause:
   10 X = 10
   20 STOP
   30 PRINT X

Trace variable values:
   10 FOR I = 1 TO 10
   20     PRINT "I ="; I
   30     ' Your code
   40 NEXT I

Check array bounds:
   10 DIM A(10)
   20 PRINT "LBOUND:"; LBOUND(A)
   30 PRINT "UBOUND:"; UBOUND(A)


C.3 PERFORMANCE TIPS
--------------------

Use integer variables when possible:
   ' Slow:
   FOR I = 1 TO 1000
   
   ' Faster:
   FOR I% = 1 TO 1000

Minimize operations in loops:
   ' Slow:
   FOR I = 1 TO 1000
       RESULT = I * 3.14159 / 2
   NEXT I
   
   ' Faster:
   CONSTANT = 3.14159 / 2
   FOR I = 1 TO 1000
       RESULT = I * CONSTANT
   NEXT I

Use ERASE for large arrays:
   DIM TEMP(10000)
   ' Use array
   ERASE TEMP
